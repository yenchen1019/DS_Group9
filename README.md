# 郁見電影 漫遊四方 — 電影導向網頁搜尋引擎

> 一個以電影為核心的網頁搜尋引擎，透過自訂評分機制，讓電影相關網頁在搜尋結果中獲得更高排名。

---

## 專案簡介（Introduction）

本專案旨在開發一個以**電影**為核心的網頁搜尋引擎，提供類似一般搜尋引擎的使用體驗。

使用者只需要輸入一個字詞，系統便會自動取得網路上的搜尋結果，分析各個網頁的內容，並透過自訂的評分公式重新排列搜尋結果，優先呈現與電影領域相關的網頁。

例如，當使用者輸入「狗」時，系統會嘗試找出以狗為主角、包含狗的角色，或以狗為重要題材的電影相關網頁，而不只是一般的寵物介紹或動物知識網站。

## 專案目標（Objectives）

- 建立以電影領域為核心的網頁搜尋引擎。
- 支援使用者輸入任意關鍵字進行搜尋。
- 自動取得網路上的候選網頁。
- 分析網頁內容與電影相關資訊。
- 透過自訂評分公式計算網頁的電影相關程度。
- 根據評分結果重新排列搜尋結果。

## 評分機制（Scoring Mechanism）

本系統透過自訂的關鍵字權重，分析搜尋結果網頁與電影領域的相關程度，並依據計算出的分數重新排列搜尋結果。

### 評分項目

| 分類 | 關鍵字範例 | 權重 |
| :--- | :--- | :---: |
| 電影基本資訊 | 電影、上映、導演、主演、片長、預告、電影院 | +5 |
| 電影類型 | 動作、愛情、喜劇、恐怖、科幻、懸疑、動畫、紀錄片 | +5 |
| 電影評價 | 影評、心得、評價、推薦、評分、口碑 | +1 |
| 上映資訊 | 場次、戲院、票房、分級、首映 | +3 |
| 電影製作 | 幕後、花絮、拍攝、取景、原著 | +3 |
| 電影獎項 | 奧斯卡、金馬獎、坎城影展、最佳影片、最佳導演 | +3 |
| 劇情相關 | 劇透、暴雷、彩蛋、劇情反轉、開放式結局 | +1 |
| 電影院名稱 | 威秀、秀泰、美麗華、國賓、樂聲影城 | +2 |
| 電影技術 | IMAX、3D、4D、Dolby Cinema | +4 |
| 電影製作公司 | Disney、Universal、Warner Bros.、Paramount | +2.5 |
| 電影相關食品 | 爆米花、碳酸飲料、熱狗、吉拿棒 | +1 |

### 評分方式

系統會分析各候選網頁的內容，統計電影相關關鍵字的出現情況，並乘上各分類所設定的權重，計算網頁的電影相關分數。

基本概念如下：

**網頁相關分數 = 各關鍵字出現次數 × 對應權重的總和**

### 排序方式

1. 擷取候選網頁的 HTML 內容。
2. 分析網頁中的電影相關關鍵字。
3. 根據關鍵字分類及權重計算分數。
4. 將各網頁的分數進行比較。
5. 依照分數由高至低重新排列搜尋結果。

### 評分目的

透過電影領域關鍵字的加權評分，讓包含較多電影相關資訊的網頁獲得較高排名，降低一般非電影相關網頁出現在搜尋結果前段的機率。

## 開發環境與使用技術（Tech Stack）

### Programming Language
- Java

### Development Tools
- Visual Studio Code
- Apache Maven

### Core Technologies
- Search API：取得網路搜尋結果及候選網頁網址。
- HTML Parsing：擷取及解析網頁內容。
- Keyword Matching：比對搜尋字詞與電影相關關鍵字。
- Weighted Scoring：依據不同關鍵字權重計算網頁相關分數。
- Tree Structure：建立網頁與子網頁之間的階層關係。
- Ranking Algorithm：根據計算結果重新排列搜尋結果。
